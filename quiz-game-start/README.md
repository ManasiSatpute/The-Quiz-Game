# Python Quiz Game 

A simple command-line quiz game built using Python.  
The game presents true/false trivia questions, takes user input, and tracks the final score.

Trivia questions are sourced from the **Open Trivia Database (OpenTDB)** and stored in a structured format, allowing the quiz topic to be easily changed.

---

##  Features
- Command-line based quiz game
- True / False question format
- Object-Oriented Programming (OOP) design
- Easy to switch quiz topics
- Final score tracking

---

##  Technologies Used
- Python 3
- Object-Oriented Programming (OOP)
